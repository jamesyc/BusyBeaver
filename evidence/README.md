# Verification records

The [verification summary](../docs/validation.md) describes the package
checks, build results, and axiom audits.

| Record | Contents |
|---|---|
| [File manifest](source-manifest.json) | Original checkout paths and SHA-256 hashes. |
| [Palomar port manifest](palomar-source-manifest.json) | SHA-256 hashes for new and substantively changed files in the module port. |
| [Build record](publication/local-validation.json) | Serial build, default package builds, and interface checks. |
| [Core axiom report](publication/core-axioms.txt) | Eight physical and runtime declarations. |
| [Endpoint axiom report](publication/endpoint-axioms.txt) | Nine declarations covering the literal endpoint and both sides of independence. |

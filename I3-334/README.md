# I3-334

Lean verifies conditional independence from ZFC + I3 for a literal
two-symbol machine with 334 working states. Its blank-tape nonhalting
is equivalent to syntactic consistency of ZFC + I3. The Lake project,
proof support, and optimized Foundation sources are bundled here.
